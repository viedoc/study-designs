# Example ODM File for Viedoc Repeating Item Groups

This folder contains an **example CDISC ODM XML file** used in the *Repeating Item Groups* webinar hosted by Viedoc, and an associated **example reference data scope**.

The OMD file illustrates how repeating item groups can be configured in forms in Viedoc Designer and how associated reference data scopes can be configured. The reference data scope file can be uploaded in the global design settings to illustrate how the configuration could look like when using repeating item groups. 

Note that the design is not using CDASH compliant OIDs and is intended as an example for inspiration rather than to be copied and used as is.
 
The ODM file in this repo is an XML-formatted representation of a study design that includes repeating item group constructs. It follows the **CDISC ODM standard**, which is a vendor-neutral format for exchanging clinical study metadata and data. ODM is widely used in clinical data management and is supported by Viedoc for design and data import workflows.
